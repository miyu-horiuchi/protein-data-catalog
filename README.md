# protein-data-catalog

Public data-availability catalog for PPARγ, GCK, Aurora A, and ERK2.

**[Open the catalog in your browser](https://htmlpreview.github.io/?https://github.com/miyu-horiuchi/protein-data-catalog/blob/main/catalog.html)**

The catalog opens with an availability table for all four targets. Use the **Sources and datasets**, **Individual files**, and **PDB records** tabs to browse the full catalog. Filter by target or search by accession, assay, or filename.

[Download the original interactive HTML](https://raw.githubusercontent.com/miyu-horiuchi/protein-data-catalog/main/index.html).
